2. Open he.html for Hebrew / פתחי he.html לעברית
3. Both pages have language switching links and embedded profile photos.

5. The preview.jpg is included for future social sharing. After publishing, set og:image on both pages to its full public HTTPS URL (e.g. https://YOUR-DOMAIN/preview.jpg). Local file links do not create WhatsApp previews.
